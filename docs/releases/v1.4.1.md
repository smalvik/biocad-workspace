The real two-process race experiment found a PostgreSQL GiST deadlock that could
return HTTP 500 while still preventing overlap. Native `ON CONFLICT DO NOTHING
RETURNING` now arbitrates existing booking/idempotency constraints; bounded complete
transaction retry covers residual `40P01`. Exhaustion returns retryable 503 with no
booking/event, preserving the same idempotency key. No schema change.

The test-only probe creates its own database, synchronizes two real INSERTs, removes
only its child constraint and records genuine RED **2 failed**; exact restoration
and the same source-hashed oracle produce GREEN **3 passed**. Half-open adjacency,
cancel/rebook, ownership guards and child cleanup are verified. Probe/pytest are
physically absent from the published runtime image.
