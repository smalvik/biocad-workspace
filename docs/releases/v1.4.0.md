PostgreSQL outbox, persistent RabbitMQ and independent Notification Worker. HTML/plain
emails show fictional full name/address, resource/floor, Moscow interval, booking ID,
application CTA and demo support contact. Worker owns durable retry/dedup state;
broker/SMTP failures do not undo bookings. SMTP acceptance/commit ambiguity is explicit.

Nine immutable runtime/test image digests in schema 2; four runtime images receive
version/latest aliases only after validation. Seven-image v1.3.1 rollback remains
supported without a new Booking migration or deleting Worker state.
