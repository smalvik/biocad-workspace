# Secrets and production safety
Never paste tokens into Codex/ChatGPT messages, issue trackers, screenshot, logs or README. Use local untracked `.env`/secret manager and GitHub Actions environment/repository secrets for workflow tokens. Suggested names: `OPENROUTER_API_KEY`, `OPENROUTER_PRIMARY_MODEL`, `OPENROUTER_FALLBACK_MODEL`, `DATABASE_URL`, `RABBITMQ_URL`, `SESSION_SECRET`, `DOCKERHUB_USERNAME`, `DOCKERHUB_TOKEN`, `SSH_PRIVATE_KEY`, `DEPLOY_HOST`, `DEPLOY_USER`, `WEBHOOK_SECRET`. No actual values included in this package. Restrict GitHub PAT scopes and set expirations. Do not store real employee personal data or private feedback in unconstrained free LLM prompts.
