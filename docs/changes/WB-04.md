# WB-04 · Поиск сотрудников и аватарки

## Пользовательское изменение
Поиск по ФИО/отделу, переход на этаж и выделение места, профили в правой панели.
На постоянных и забронированных FreeDesk — вымышленные аватары выбранного периода.
На свободных местах аватаров нет; при нескольких бронях — стек/счётчик и весь таймлайн.

## Реальная реализация
Booking: authenticated `/employees`, `/employees/{id}/location` и canonical
`/floors/{id}/occupancy`; безопасная проекция без account/session/private fields,
batch joins без запроса профиля на каждое место. Поиск ILIKE/Unicode, буквальные
LIKE-метасимволы, валидация aware интервала `[start,end)`, только confirmed брони.
React: sidebar search, cross-floor selection, responsive sheet, полные даты/время МСК,
несколько локаций, initials при сбое картинки, AbortController/ключи запроса и защита
от позднего ответа после ручного выбора. Ошибка поиска не блокирует карту.
12 оригинальных SVG-иллюстраций; реальные фотографии/внешний avatar-сервис не используются.
Seed обновляет только demo avatar_url у вымышленных профилей, не меняет аккаунты/брони.
Миграция не нужна: поле avatar_url уже существует. Гарантии записи WB-02 не менялись.
