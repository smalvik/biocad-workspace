# WB-06 · AI + MCP

Чат находит актуальное место/переговорную через настоящий LLM и MCP, предлагает
ресурс на плане и открывает отдельное подтверждение точного места/даты/времени.
Бронь создаёт только Booking после действия пользователя; при сбое AI ручная форма работает.
Опубликована [v1.3.0](https://github.com/smalvik/biocad-workspace/releases/tag/v1.3.0),
production **https://biocad.smalvik.dev**, source **19a8388** / main PR #26.

## Реализация

- Booking RPC через durable RabbitMQ переиспользует auth/CSRF/booking handlers
  внутри Booking ASGI-процесса; нет HTTP-связи сервисов или доступа Assistant к БД.
- Official MCP SDK 2.3.0 STDIO, discovery и read tools `search_employees`,
  `list_spaces`, `get_availability`, `get_space_details`. `propose_booking`
  повторно проверяет доступность и подписывает предложение, write-tool отсутствует.
- Согласие пользователя; только OpenRouter `inclusionai/ling-3.2-flash:free`,
  бюджет $0, свежая проверка бесплатной модели/tool support и zero price caps;
  paid fallback отключён. Ограничены input/output/tools/rounds/time и один retry 429.
- User-bound предложение на 10 минут, отдельный `/assistant/confirm`, стабильный
  ключ retry/reload. Истёкшее предложение может восстановить прежний commit до
  8 часов, но не создать новую бронь. Существующие GiST/idempotency/outbox сохранены.
- Аддитивная `0003_assistant_limits`: durable rate windows, runtime free-only
  отвергает платную ветку, допускает бесплатную при бюджете 0; 3 запроса/user/min.
- React chat/history/abort, map highlight, точное подтверждение, mobile preview.
  [Контракт и эксплуатация](../architecture/ASSISTANT.md).
