# WB-09 · Immutable images and isolated server delivery

Implements same-repository PR candidate publication, complete develop/main regression,
seven digest-pinned runtime/test images, server regression, private staging, production
promotion, protected cookies/HTTPS/source smoke, PostgreSQL backup and image rollback.
Version/latest aliases and GitHub release/evidence publish only after production smoke.
Only three implemented services receive runtime version tags; no fictitious notifier.

Server inspected through password access explicitly supplied by the owner, then a new
BIOCAD administrator key was installed without removing existing keys. Its path and a
separate CI key path are in ignored `.env`. The CI key belongs to a dedicated forced-command
user without Docker group membership. Root-owned dispatcher and environment secrets were
bootstrapped in `/opt/biocad`. Existing containers and proxy were not restarted or reconfigured.

Actual ingress is existing Traefik, not host Nginx. Only production Web optionally joins
its existing ingress network; all data/API services and staging remain on private project
networks. Loopback ports 18080/18081 were checked free during bootstrap.
