## Пользовательское изменение

фильтры типов/доступности, SVG pan/zoom/fit и карточка ресурса.

## Реальная реализация
React-компоненты используют геометрию/занятость Booking API. Alembic 0002 добавляет
floor plan JSONB; seed обновляет только геометрию существующих ресурсов, сохраняя
брони/аккаунты. Главный этаж 24 desk/3 rooms, второй 12 desk/2 rooms.
Вход/выход используют настоящие сессии WB-02. Старые ответы календаря отбрасываются,
при смене интервала старый snapshot скрывается; refresh/polling 25 с.
Состояния loading/error/empty/session expiry, клавиатурный выбор, мобильная карточка.
