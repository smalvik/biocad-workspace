# WB-01 · Техническая основа

Included in published [v1.0.0](https://github.com/smalvik/biocad-workspace/releases/tag/v1.0.0);
[actual remote lifecycle/evidence](../evidence/WB-09-remote.md). Earlier checks below retain their original scope.

## Пользовательское изменение
Локальный каркас React и двух FastAPI-сервисов с PostgreSQL, RabbitMQ и Mailpit.
Страница показывает доступность API через nginx. Бронирований, карты и реального AI пока нет.

## Реальная реализация
Сохранён ранее написанный незакоммиченный каркас. Добавлены Compose health gates,
volumes брокера/почты, ограничение времени PostgreSQL readiness, изолированный
`scripts/check.py`, unit/integration/browser smoke, Allure metadata и CI workflow.
Тестовый проект без host ports удаляет только свои volumes; LLM-ключи отключены.
